# Presentación Quarto + RevealJS: fisiología del ictus y relación con sEMG

## Render

```bash
quarto render fisiologia_ictus_semg_reveal.qmd
```

## Salida esperada

- `fisiologia_ictus_semg_reveal.html`: presentación RevealJS.
- `referencias.bib`: bibliografía académica.
- `estilos_reveal.css`: estilo visual de las diapositivas.

## Tema

Ictus isquémico / enfermedad cerebrovascular post-ictus, con énfasis en alteración del control motor, hemiparesia y uso de sEMG como ventana no invasiva de la activación neuromuscular.
