Introducción práctica a la terminal

Gestión de archivos y configuración básica en Garuda Linux (fish y Bash) y Windows PowerShell

Tutorial comparativo para aprender a trabajar de forma segura con archivos, directorios y configuraciones básicas desde fish y Bash en Garuda Linux, y desde PowerShell en Windows.
Autor/a

Ph.D. Pablo Eduardo Caicedo Rodríguez

Fecha de publicación

27 de septiembre de 2026

Propósito del tutorial

La terminal permite controlar el sistema operativo mediante instrucciones escritas. No reemplaza por completo a la interfaz gráfica, pero resulta más precisa para organizar archivos, repetir tareas, diagnosticar problemas y documentar procedimientos reproducibles.

Esta guía presenta tres rutas:

  • Garuda Linux con fish, el shell interactivo que abre Konsole en Garuda. Es la ruta principal de esta versión.
  • Garuda Linux con Bash, el shell de inicio de sesión de Garuda y el estándar de Ubuntu, Pop!_OS, servidores y clústeres.
  • Windows con PowerShell, incluido en Windows y basado en comandos llamados cmdlets.

No es necesario estudiar las tres simultáneamente. Cada estudiante puede seguir la ruta correspondiente a su sistema y utilizar las tablas comparativas para reconocer equivalencias. Cuando fish y Bash aceptan exactamente el mismo comando, la guía los muestra en una sola pestaña, Garuda · fish y Bash.

NotaVersiones de referencia

Comprobado el 27 de septiembre de 2026 con la edición Garuda Dr460nized (KDE Plasma 6), fish 4.9.3 (paquete fish de Arch Linux) y la configuración que Garuda instala mediante los paquetes garuda-fish-config y garuda-bash-config. Garuda es una distribución rolling release: si una salida difiere ligeramente, consulte la versión con fish --version.

NotaResultados de aprendizaje

Al finalizar, el estudiante estará en capacidad de:

  1. diferenciar terminal, consola, shell y símbolo del sistema;
  2. reconocer si trabaja en fish o en Bash y cuándo conviene usar cada uno;
  3. navegar por el sistema de archivos utilizando rutas absolutas y relativas;
  4. crear, consultar, copiar, mover, renombrar y eliminar archivos de forma controlada;
  5. buscar archivos y contenido sin depender de la interfaz gráfica;
  6. identificar los alias que Garuda agrega (ls, cat, grep) y acceder al comando original;
  7. interpretar variables de entorno, permisos, procesos, almacenamiento y red;
  8. personalizar de forma básica y reversible una sesión de fish, Bash o PowerShell;
  9. ejecutar una práctica reproducible sin modificar archivos importantes del equipo.

Antes de comenzar

Abrir la terminal

  • Garuda · fish
  • Garuda · Bash
  • Windows PowerShell

En Garuda Dr460nized la terminal predeterminada es Konsole. Se abre normalmente con Ctrl + Alt + T o buscando Konsole en el lanzador de aplicaciones.

El perfil de Konsole que trae Garuda inicia fish, aunque el shell de inicio de sesión del usuario siga siendo Bash. Al abrirse, fish muestra un resumen del sistema (fastfetch) y un prompt generado por Starship.

Para confirmar qué shell está interpretando sus comandos:

ps -p $fish_pid -o comm=
echo $version
  • $fish_pid contiene el identificador del proceso de fish; la primera orden debe responder fish.
  • $version contiene la versión de fish.
Advertencia$SHELL no responde esta pregunta

La configuración de Garuda para fish exporta SHELL=/usr/bin/fish, de modo que echo $SHELL muestra fish dentro de fish. Sin embargo, el shell de inicio de sesión registrado para el usuario sigue siendo Bash:

getent passwd $USER | cut -d: -f7

Por esa razón, otras terminales como kitty o Alacritty abren Bash salvo que se configuren para abrir fish. $SHELL indica un valor de configuración, no el proceso que se está ejecutando.

Si su terminal abre Bash, o si desea practicar la ruta Bash desde Konsole, escriba:

bash

Para confirmar el shell actual y regresar a fish:

ps -p $$ -o comm=
echo "$BASH_VERSION"
exit

$$ contiene el identificador del proceso actual en Bash. exit cierra la sesión de Bash y devuelve el control al fish que la inició.

Abra el menú Inicio y busque PowerShell o Terminal. Windows Terminal es una aplicación que puede contener sesiones de PowerShell, Símbolo del sistema y otros shells.

Para consultar la edición y versión de PowerShell:

$PSVersionTable

Los ejemplos usan PowerShell. No deben copiarse directamente en cmd.exe, porque ambos intérpretes tienen sintaxis diferente.

Regla de seguridad para toda la guía

La práctica se realizará únicamente dentro de una carpeta llamada Terminal_Practica, creada en la carpeta personal del usuario.

AdvertenciaLea antes de ejecutar
  • Revise el comando completo antes de presionar Enter.
  • Confirme la carpeta actual antes de copiar, mover o eliminar archivos.
  • Use comillas cuando una ruta contenga espacios.
  • No ejecute comandos que no comprenda.
  • No use privilegios de administrador (sudo) para completar este tutorial.
  • Evite rm -rf, Remove-Item -Recurse -Force y órdenes similares. Un error en la ruta puede eliminar información importante sin confirmación.
  • En Garuda, no ejecute los alias de mantenimiento que traen sudo (fixpacman, rmpkg, cleanup, mirror, grubup) como parte de esta práctica.
NotaLas instantáneas de Garuda no protegen su carpeta personal

Garuda crea instantáneas Btrfs con Snapper antes y después de cada operación de pacman, pero la configuración que instala (snapper-support) solo cubre el subvolumen raíz (/). La carpeta personal (/home) está en otro subvolumen, por lo que un archivo borrado en ~/Terminal_Practica no se recupera desde esas instantáneas.

Terminal, shell y comando

Los términos se relacionan, pero no significan lo mismo:

Concepto Función Ejemplo
Terminal Interfaz en la que se escriben y observan comandos Konsole, kitty, Windows Terminal
Shell Programa que interpreta los comandos fish, Bash, PowerShell
Línea de comandos Forma de interacción mediante texto ls -la, Get-ChildItem -Force
Prompt Texto que indica que el shell espera una instrucción ❯ (Starship en Garuda), usuario@equipo:~$, PS C:\>

Un comando suele tener tres componentes:

comando  opciones  argumentos

Por ejemplo, en Linux (idéntico en fish y Bash):

ls -l datos
  • ls: programa o comando;
  • -l: opción que solicita una vista detallada;
  • datos: directorio sobre el cual se ejecuta la operación.

En PowerShell es común la estructura Verbo-Sustantivo:

Get-ChildItem -Path datos
  • Get-ChildItem: cmdlet;
  • -Path: parámetro;
  • datos: valor del parámetro.
TipQué se debe escribir

Los bloques de código muestran únicamente el comando. Si en otra fuente aparece un prompt como ❯, $, usuario@equipo:~$ o PS C:\>, no lo copie: ese texto representa el estado de la terminal y no forma parte de la instrucción.

ImportanteDiferencia fundamental

En fish y en Bash, una tubería transporta texto. En PowerShell, una tubería normalmente transporta objetos con propiedades y métodos. Por esta razón, dos comandos visualmente equivalentes pueden requerir formas distintas de filtrado.

fish y Bash: dos shells en el mismo sistema

fish (friendly interactive shell) está pensado para el uso interactivo: sugiere comandos mientras se escribe, colorea la sintaxis y completa opciones con descripciones. A cambio, no es compatible con la sintaxis POSIX de Bash. La mayoría de los comandos cotidianos se escriben igual, pero cambian las variables, los bucles, las condiciones y algunos operadores.

Tarea Bash fish
Asignar una variable CURSO="SYSB" set CURSO SYSB
Exportar una variable export CURSO="SYSB" set -gx CURSO SYSB
Eliminar una variable unset CURSO set -e CURSO
Código de salida del último comando $? $status
Identificador del proceso actual $$ $fish_pid
Sustitución de comandos $(pwd) (pwd) o $(pwd)
Bucle for f in *.csv; do echo "$f"; done for f in *.csv; echo $f; end
Condición if [ -f a.txt ]; then ...; fi if test -f a.txt; ...; end
Documento en línea (heredoc) cat <<EOF ... EOF No existe; use printf o un editor
Archivo de configuración ~/.bashrc ~/.config/fish/config.fish

Los operadores &&, ||, |, >, >>, 2> y &> funcionan en ambos.

TipCriterio recomendado

Use fish para trabajar de forma interactiva y escriba los scripts en Bash, con #!/usr/bin/env bash en la primera línea. fish ejecuta esos scripts sin problema porque la primera línea indica el intérprete, y el mismo script funcionará en Ubuntu, en un servidor o en un clúster. Si una instrucción copiada de Internet falla en fish, escriba bash, ejecútela allí y regrese con exit.

Ventajas interactivas de fish

Estas funciones no requieren configuración en Garuda:

  • Autosugerencias: mientras escribe, fish propone en gris un comando del historial. → o Ctrl + F acepta la sugerencia completa; Alt + → acepta una palabra.
  • Resaltado de sintaxis: un comando inexistente aparece en rojo antes de ejecutarlo.
  • Completado con descripción: Tab muestra las opciones de un comando con su explicación, por ejemplo tar - seguido de Tab.
  • Búsqueda en el historial: Ctrl + R abre el historial en un panel filtrable.
  • Historial de carpetas: cd - vuelve a la carpeta anterior; prevd y nextd recorren las carpetas visitadas, y cdh muestra la lista.
  • !! en Garuda: Garuda agrega un atajo para que !! se sustituya por el comando anterior al escribirlo, como en Bash.

El sistema de archivos

Rutas, carpetas y separadores

Una ruta absoluta identifica una ubicación desde la raíz del sistema. Una ruta relativa se interpreta desde la carpeta de trabajo actual.

Elemento Garuda (fish y Bash) Windows PowerShell
Raíz principal / C:\
Carpeta personal /home/usuario C:\Users\usuario
Abreviatura de la carpeta personal ~ o $HOME $HOME
Separador habitual / \
Carpeta actual . .
Carpeta superior .. ..

Ejemplos:

# Ruta absoluta en Linux
/home/ana/Terminal_Practica/datos/ecg_01.csv

# Ruta relativa en Linux
datos/ecg_01.csv

# Ruta absoluta en Windows
C:\Users\Ana\Terminal_Practica\datos\ecg_01.csv

# Ruta relativa en Windows
datos\ecg_01.csv
NotaMayúsculas y minúsculas

Linux distingue Datos, datos y DATOS como nombres diferentes. Windows normalmente no los distingue al resolver una ruta, aunque conserva la forma escrita. Use nombres consistentes y evite depender de esta diferencia.

Preparar el entorno seguro de práctica

Ejecute solo el bloque correspondiente a su sistema.

  • Garuda · fish y Bash
  • Windows PowerShell
cd "$HOME"
mkdir -p Terminal_Practica/{datos,reportes,scripts,respaldo}
cd Terminal_Practica
pwd

mkdir -p crea las carpetas requeridas y no produce un error si ya existen. La expansión entre llaves {datos,reportes,...} funciona igual en fish y en Bash: el shell la convierte en cuatro rutas antes de ejecutar mkdir.

$base = Join-Path $HOME "Terminal_Practica"
New-Item -ItemType Directory -Path $base -Force | Out-Null
Set-Location $base
"datos", "reportes", "scripts", "respaldo" |
    ForEach-Object { New-Item -ItemType Directory -Path $_ -Force | Out-Null }
Get-Location

Join-Path construye una ruta sin escribir manualmente el separador. Out-Null oculta la salida informativa de creación.

La estructura esperada es:

Terminal_Practica/
├── datos/
├── reportes/
├── respaldo/
└── scripts/

En Garuda puede verificarla con el alias lt, que muestra un árbol mediante eza:

lt

Comandos esenciales

Tarea Garuda (fish y Bash) Windows PowerShell
Mostrar la ubicación actual pwd Get-Location
Listar elementos ls Get-ChildItem
Incluir elementos ocultos ls -la Get-ChildItem -Force
Entrar a una carpeta cd datos Set-Location datos

PowerShell también reconoce varios alias breves, como cd, ls y pwd. Para aprender procedimientos portables y legibles, es preferible usar el nombre completo de los cmdlets en scripts.

Los alias que agrega Garuda

Garuda reemplaza algunos comandos clásicos por herramientas modernas mediante alias definidos tanto en fish (garuda-fish-config) como en Bash (garuda-bash-config). Esto cambia la apariencia de varias salidas de esta guía.

Escribe Garuda ejecuta en realidad Para usar el comando original
ls eza -al --group-directories-first command ls
ll, la, lt variantes de eza (larga, ocultos, árbol) command ls -l
cat bat --style header,snip,changes command cat
grep ugrep --color=auto command grep
ip ip -color command ip
.., ... cd .., cd ../.. cd ..

Consecuencias prácticas:

  • ls ya incluye archivos ocultos y vista detallada, porque el alias agrega -al.
  • eza muestra los permisos con un punto inicial para archivos (.rw-r--r--) en lugar del guion de ls (-rw-r--r--).
  • cat muestra un encabezado con el nombre del archivo y color de sintaxis. Cuando su salida va a una tubería o a un archivo, bat entrega el texto sin decoración.
  • Los alias existen solo en sesiones interactivas. Un script ejecuta los programas originales (ls, cat, grep de GNU).

Para averiguar qué ejecutará realmente un nombre:

  • Garuda · fish
  • Garuda · Bash
  • Windows PowerShell
type ls
type cat
functions ll

En fish, cada alias es en realidad una función; type y functions muestran su definición.

type ls
alias

alias sin argumentos lista todos los alias activos.

Get-Alias ls
Get-Command ls

Autocompletado e historial

  • Tab: completa comandos, parámetros o rutas.
  • Flecha ↑ y flecha ↓: recorren comandos anteriores. En fish, si ya escribió parte de un comando, las flechas buscan solo entre los que empiezan así.
  • Ctrl + C: interrumpe el comando activo; no significa “copiar” en la mayoría de terminales. En Konsole, copiar es Ctrl + Shift + C.
  • Ctrl + L: limpia visualmente la terminal en fish y en Bash.
  • Garuda · fish
  • Garuda · Bash
  • Windows PowerShell
history
builtin history --max 10
builtin history search --contains csv

Garuda redefine history para mostrar la fecha y hora de cada comando, pero esa versión ignora las opciones. Para limitar o filtrar use builtin history, que invoca la orden original de fish. En fish, history 10 no significa “diez comandos”: buscaría el texto 10.

El historial de fish se guarda automáticamente en ~/.local/share/fish/fish_history y se comparte entre sesiones.

history
history 10

En Bash, history 10 muestra los diez comandos más recientes. El historial se guarda en ~/.bash_history al cerrar la sesión.

Get-History
Get-History -Count 10

Get-History consulta el historial de la sesión actual. El historial interactivo persistente puede depender del módulo PSReadLine.

Crear archivos y consultar su contenido

Crear un archivo de datos pequeño

Desde Terminal_Practica, cree un CSV de ejemplo:

  • Garuda · fish y Bash
  • Windows PowerShell
printf "muestra,ecg_mV\n0,0.02\n1,0.18\n2,0.73\n3,0.21\n" \
  > datos/ecg_01.csv

printf interpreta \n como salto de línea en ambos shells. La barra invertida al final de la primera línea indica que el comando continúa en la siguiente.

@"
muestra,ecg_mV
0,0.02
1,0.18
2,0.73
3,0.21
"@ | Set-Content -Path datos\ecg_01.csv
AdvertenciaRedirección

El operador > crea un archivo o reemplaza su contenido. El operador >> agrega contenido al final. Antes de usar >, verifique que el archivo de destino no contenga información que deba conservarse.

fish ofrece además >?, que escribe solo si el archivo no existe; si existe, falla sin tocarlo. Bash ofrece una protección equivalente con set -o noclobber.

Agregue una línea al archivo:

  • Garuda · fish y Bash
  • Windows PowerShell
printf "4,-0.05\n" >> datos/ecg_01.csv
"4,-0.05" | Add-Content -Path datos\ecg_01.csv

Leer e inspeccionar

  • Garuda · fish y Bash
  • Windows PowerShell
cat datos/ecg_01.csv
head -n 3 datos/ecg_01.csv
tail -n 2 datos/ecg_01.csv
wc -l datos/ecg_01.csv
file datos/ecg_01.csv
  • cat muestra todo el contenido de un archivo pequeño. En Garuda, el alias usa bat y agrega un encabezado; command cat muestra el texto sin formato.
  • head y tail muestran el inicio y el final.
  • wc -l cuenta líneas.
  • file intenta identificar el tipo de contenido.

Para un archivo largo, use un visor paginado:

less datos/ecg_01.csv

Dentro de less, presione q para salir.

Get-Content datos\ecg_01.csv
Get-Content datos\ecg_01.csv -Head 3
Get-Content datos\ecg_01.csv -Tail 2
(Get-Content datos\ecg_01.csv | Measure-Object -Line).Lines
Get-Item datos\ecg_01.csv | Format-List Name, Length, LastWriteTime

Para observar contenido página por página:

Get-Content datos\ecg_01.csv | more

Archivos y carpetas con espacios

Las comillas evitan que el shell interprete cada palabra como un argumento separado.

  • Garuda · fish y Bash
  • Windows PowerShell
mkdir -p "reportes/primer informe"
cd "reportes/primer informe"
cd ../..

Una diferencia útil: en fish, una variable que contiene espacios se pasa siempre como un solo argumento, aunque no lleve comillas. En Bash, una variable sin comillas se divide en palabras, por lo que se escribe "$ruta".

New-Item -ItemType Directory -Path "reportes\primer informe" -Force
Set-Location "reportes\primer informe"
Set-Location ..\..

Aunque los espacios son válidos, nombres como primer_informe o primer-informe facilitan la automatización y reducen errores.

Copiar, renombrar, mover y eliminar

Copiar y crear respaldo

  • Garuda · fish y Bash
  • Windows PowerShell
cp datos/ecg_01.csv respaldo/ecg_01.csv
cp -i datos/ecg_01.csv respaldo/ecg_01.csv

La opción -i solicita confirmación antes de sobrescribir un archivo existente.

En fish, Garuda agrega la función backup, que crea una copia con extensión .bak junto al original:

backup datos/ecg_01.csv

backup usa cp sin -i: si ecg_01.csv.bak ya existe, lo reemplaza sin preguntar.

Copy-Item -Path datos\ecg_01.csv -Destination respaldo\ecg_01.csv
Copy-Item -Path datos\ecg_01.csv -Destination respaldo\ecg_01.csv -Confirm

-Confirm solicita autorización antes de realizar la operación.

Renombrar y mover

En Linux, mv sirve tanto para renombrar como para mover. PowerShell ofrece comandos separados para expresar mejor la intención.

  • Garuda · fish y Bash
  • Windows PowerShell
cp datos/ecg_01.csv datos/ecg_temporal.csv
mv datos/ecg_temporal.csv datos/ecg_copia.csv
mv datos/ecg_copia.csv respaldo/
Copy-Item datos\ecg_01.csv datos\ecg_temporal.csv
Rename-Item datos\ecg_temporal.csv ecg_copia.csv
Move-Item datos\ecg_copia.csv respaldo\

Después de cada operación, compruebe el resultado:

  • Garuda · fish y Bash
  • Windows PowerShell
find . -maxdepth 2 -type f
Get-ChildItem -File -Recurse

Eliminar de forma controlada

Primero cree un archivo prescindible y luego elimínelo con confirmación:

  • Garuda · fish y Bash
  • Windows PowerShell
touch datos/borrar_prueba.txt
command ls -l datos/borrar_prueba.txt
rm -i datos/borrar_prueba.txt

Para eliminar una carpeta, use rmdir cuando esté vacía:

mkdir carpeta_vacia
rmdir carpeta_vacia

Si prefiere que el archivo vaya a la papelera de KDE (visible en Dolphin), use gio trash, que sigue la especificación de papelera de freedesktop:

touch datos/papelera_prueba.txt
gio trash datos/papelera_prueba.txt
gio list trash://
New-Item -ItemType File -Path datos\borrar_prueba.txt
Get-Item datos\borrar_prueba.txt
Remove-Item datos\borrar_prueba.txt -Confirm

Para una carpeta vacía:

New-Item -ItemType Directory -Path carpeta_vacia
Remove-Item carpeta_vacia -Confirm
PrecauciónEliminar no equivale a enviar a la papelera

rm y Remove-Item no trasladan el archivo a la papelera gráfica, y en Garuda las instantáneas de Snapper no cubren /home. Antes de ejecutarlos, confirme la ubicación con pwd o Get-Location, liste el objetivo y use una opción de confirmación.

Buscar archivos y contenido

Comodines

Los comodines representan patrones de nombres. Aquí fish y Bash se comportan de forma distinta:

Comodín Bash fish 4.x
* cero o más caracteres cero o más caracteres
** solo con shopt -s globstar busca también en subcarpetas
? exactamente un carácter no es comodín desde fish 4.0; es un carácter normal
[0-9] un carácter del rango no existe en fish
Patrón sin coincidencias se pasa literalmente al comando fish no ejecuta el comando y avisa No matches for wildcard

Ejemplo: *.csv coincide con los archivos cuyo nombre termina en .csv.

TipConsecuencia práctica

Cuando un patrón está destinado a otro programa, como find -name o grep --include, escríbalo entre comillas ("*.csv"). Así el shell no intenta expandirlo, y el comando funciona igual en fish, en Bash y en scripts.

  • Garuda · fish
  • Garuda · Bash
  • Windows PowerShell
ls datos/*.csv
ls **.csv
find . -type f -name "*.csv"

**.csv encuentra los CSV en la carpeta actual y en todas sus subcarpetas sin usar find. find recorre carpetas de manera recursiva desde la ruta indicada.

ls datos/*.csv
find . -type f -name "*.csv"
ls datos/ecg_0[0-9].csv

La última línea usa una clase de caracteres, disponible en Bash pero no en fish.

Get-ChildItem -Path datos -Filter *.csv
Get-ChildItem -Path . -File -Recurse -Filter *.csv

Buscar texto dentro de archivos

  • Garuda · fish y Bash
  • Windows PowerShell
grep -n "0.73" datos/ecg_01.csv
grep -Rni --include="*.csv" "ecg" .

En Garuda, grep interactivo es un alias de ugrep, que acepta las mismas opciones usadas aquí. En un script se ejecuta el grep de GNU.

Si ripgrep está instalado, rg suele ser más rápido y cómodo:

command -v rg
rg -n "0.73" datos
rg -n -i "ecg" -g "*.csv" .

Si command -v rg no devuelve nada, ripgrep no está instalado. Instalarlo requiere sudo pacman -S ripgrep y queda fuera de esta práctica.

Select-String -Path datos\ecg_01.csv -Pattern "0.73"

Repetir una operación sobre varios archivos

Aquí la sintaxis de fish y Bash difiere. Ambos bucles muestran las tres primeras líneas de cada CSV:

Integridad, compresión y respaldo

Verificar que una copia sea idéntica

Un hash resume matemáticamente el contenido de un archivo. Dos copias con el mismo SHA-256 son, con probabilidad práctica extremadamente alta, idénticas byte a byte.

  • Garuda · fish y Bash
  • Windows PowerShell
sha256sum datos/ecg_01.csv respaldo/ecg_01.csv
Get-FileHash datos\ecg_01.csv -Algorithm SHA256
Get-FileHash respaldo\ecg_01.csv -Algorithm SHA256

El hash verifica integridad, pero no reemplaza una estrategia de respaldo: si el original y la copia están en el mismo disco, una falla física puede afectar ambos.

Variables de entorno y PATH

Una variable de entorno almacena configuración disponible para los programas de una sesión. PATH contiene una lista de carpetas donde el shell busca programas ejecutables.

Consultar variables

  • Garuda · fish
  • Garuda · Bash
  • Windows PowerShell

En fish, PATH es una lista: cada carpeta es un elemento, por eso printf las imprime una por línea sin necesidad de tr. Garuda agrega ~/.local/bin al PATH de fish si esa carpeta existe.

printenv | sort

Crear una variable temporal

  • Garuda · fish
  • Garuda · Bash
  • Windows PowerShell
set -gx CURSO SYSB
echo $CURSO
set -e CURSO
  • -g (global): la variable existe durante esta sesión.
  • -x (export): los programas que se lancen desde la sesión también la verán.
  • set -e la elimina.

fish acepta además export CURSO=SYSB por compatibilidad con Bash, pero la forma propia es set -gx.

export CURSO="SYSB"
echo "$CURSO"
unset CURSO
$env:CURSO = "SYSB"
$env:CURSO

La variable desaparece al cerrar la sesión. Esta temporalidad es útil para probar una configuración antes de hacerla persistente.

AdvertenciaVariables universales en fish

fish tiene un tercer alcance, set -U (universal), que guarda la variable de forma permanente y la comparte entre todas las sesiones abiertas. Es cómodo, pero un valor universal olvidado sigue activo semanas después. Para esta práctica use solo set -gx. Puede revisar las universales existentes con set -U.

AdvertenciaNo edite PATH a ciegas

Reemplazar PATH por un valor incompleto puede impedir que el shell encuentre programas. Para una prueba temporal, agregue una ruta y conserve el valor anterior. No copie un PATH de otro equipo.

Ejemplo temporal, que agrega la carpeta scripts de la práctica:

  • Garuda · fish
  • Garuda · Bash
  • Windows PowerShell

printf '%s\n' $PATH

fish_add_path agrega la carpeta solo si existe y no está repetida. La opción -g limita el cambio a la sesión actual.

ImportanteSin -g, el cambio es permanente

fish_add_path ruta, sin opciones, guarda la carpeta en la variable universal fish_user_paths y la mantiene en todas las sesiones futuras. Para deshacerlo: set -e fish_user_paths[1] (o el índice correspondiente, visible con echo $fish_user_paths).

Permisos y ejecución de scripts

Permisos en Linux

  • Garuda · fish y Bash
command ls -l

Se usa command ls para obtener la salida clásica de GNU ls. El alias ls de Garuda (eza) muestra la misma información con otro formato.

Una salida como -rw-r--r-- se interpreta en grupos:

  • primer carácter: tipo de elemento (- archivo, d directorio; eza usa . para archivo);
  • rw-: permisos del propietario;
  • r--: permisos del grupo;
  • r--: permisos de otros usuarios;
  • r, w, x: lectura, escritura y ejecución.

Cree un script breve de Bash. El siguiente comando funciona igual en fish y en Bash porque no usa heredoc: cada texto entre comillas simples se escribe como una línea del archivo.

printf '%s\n' \
  '#!/usr/bin/env bash' \
  'set -euo pipefail' \
  'echo "Archivos CSV:"' \
  'find datos -type f -name "*.csv" | sort' \
  'echo "Líneas por archivo:"' \
  'wc -l datos/*.csv' \
  > scripts/resumen.sh

Para dar permiso de ejecución al propietario del script y ejecutarlo desde Terminal_Practica:

chmod u+x scripts/resumen.sh
./scripts/resumen.sh

Aunque se ejecute desde fish, el script corre en Bash porque su primera línea (#!/usr/bin/env bash) indica el intérprete. Por eso los alias interactivos de Garuda no intervienen dentro del script.

AdvertenciaEvite chmod 777

Otorgar lectura, escritura y ejecución a todos los usuarios suele ser innecesario y reduce la seguridad. Asigne únicamente el permiso requerido.

Seguridad de scripts en PowerShell

Consulte las políticas efectivas sin modificarlas:

Get-ExecutionPolicy -List

La política de ejecución ayuda a controlar las condiciones bajo las cuales PowerShell carga perfiles y ejecuta scripts. No es una frontera de seguridad completa y tampoco debe desactivarse para ejecutar código desconocido.

ImportanteCriterio institucional

Si un script legítimo del curso está bloqueado, revise primero su contenido y consulte la política del laboratorio o de la institución. No use Bypass, no cambie políticas del equipo y no abra PowerShell como administrador solo para omitir la restricción.

Personalización básica y reversible

Garuda ya define ll, la y lt. Para no ocultar esos alias, los ejemplos crean uno nuevo llamado lista. Antes de crear cualquier alias, compruebe que el nombre esté libre con type lista.

Alias y configuración de fish

Un alias temporal:

alias lista 'command ls -alF'
lista

En fish, alias crea una función. Para eliminarla de la sesión:

functions --erase lista

fish ofrece también abreviaturas, que se expanden en la línea antes de ejecutarse. Así el comando completo queda visible y en el historial:

abbr --add lista 'command ls -alF'

Escriba lista y un espacio: fish lo reemplaza por command ls -alF. Para quitarla: abbr --erase lista.

Para hacerla persistente, primero respalde la configuración:

cp -i ~/.config/fish/config.fish ~/.config/fish/config.fish.backup

Garuda organiza la configuración en dos niveles:

  • /usr/share/garuda/garuda-fish-config/config.fish: valores de Garuda. No lo edite; las actualizaciones lo reemplazan.
  • ~/.config/fish/config.fish: su archivo personal. Carga el anterior y contiene la línea # -- Insert customizations below this line! --.

Abra ~/.config/fish/config.fish con un editor (por ejemplo, Kate) y agregue debajo de esa línea y encima de __garuda_fastfetch:

abbr --add lista 'command ls -alF'

Después de revisar y guardar el archivo, abra una nueva pestaña de Konsole o recargue fish en la ventana actual:

exec fish
TipConfiguración gráfica

fish_config abre en el navegador una interfaz para elegir colores y consultar funciones, variables y abreviaturas. En Garuda, el prompt lo controla Starship (~/.config/starship.toml), no el tema de fish_config.

Alias y perfil de Bash

Un alias abrevia un comando durante la sesión:

alias lista='command ls -alF'
lista

Para eliminarlo de la sesión:

unalias lista

Antes de editar un archivo de configuración, cree un respaldo:

cp -i "$HOME/.bashrc" "$HOME/.bashrc.backup"

En Garuda, ~/.bashrc carga los valores de /usr/share/garuda/garuda-bash-config/bashrc y contiene la línea # -- Insert customizations below this line! --. Agregue debajo de ella:

alias lista='command ls -alF'

Después de revisar y guardar el archivo:

source "$HOME/.bashrc"

Función y perfil de PowerShell

Una función temporal equivalente puede definirse así:

function lista { Get-ChildItem -Force }

if (-not (Test-Path $PROFILE)) {
    New-Item -ItemType File -Path $PROFILE -Force
}

Abra el archivo con un editor y agregue únicamente:

function lista { Get-ChildItem -Force }

La carga del perfil depende de la política de ejecución vigente. No cambie esa política únicamente para activar una abreviatura.

Un equipo de estudiantes recibió pequeños archivos de señales biomédicas y debe preparar una estructura reproducible para analizarlos. La práctica evalúa organización, trazabilidad e integridad; no evalúa procesamiento digital de señales.

Errores frecuentes y diagnóstico

“No se reconoce el comando” o “command not found”

Posibles causas:

  • el comando está mal escrito;
  • el programa no está instalado;
  • la carpeta del programa no está en PATH;
  • se copió un comando de Bash en PowerShell, o viceversa.

En fish, un comando inexistente se marca en rojo antes de ejecutarlo. En Garuda, además, pkgfile sugiere qué paquete contiene el programa que falta.

Un bloque largo de instalación ejecútelo en bash y regrese con exit

fish no ejecuta un comando con comodines

Si fish responde No matches for wildcard, el patrón no coincidió con ningún archivo y fish decidió no ejecutar la orden. Verifique la carpeta actual o escriba el patrón entre comillas si está destinado a otro programa (find . -name "*.csv"). Recuerde que ? y [0-9] no son comodines en fish 4.x.

“No existe el archivo o directorio”

  1. Consulte la carpeta actual.
  2. Liste sus elementos.
  3. Revise mayúsculas, extensión y comillas.
  4. Pruebe primero con una ruta absoluta.

“Permiso denegado”

No asuma que la solución es ejecutar como administrador. Verifique:

  • quién es el propietario;
  • qué permisos tiene el elemento;
  • si otro programa mantiene el archivo abierto;
  • si se intenta escribir en una ubicación protegida;
  • si la política institucional restringe scripts.

El comando parece no terminar

  • Espere si la tarea procesa muchos archivos.
  • Revise si el programa solicita una entrada o confirmación.
  • Revise si quedó abierto un visor (less, man, bat): presione q.
  • Use Ctrl + C para interrumpir una tarea propia cuando sea necesario.
  • No cierre abruptamente la terminal mientras un programa escribe un archivo importante.

Cierre

El dominio de la terminal no consiste en memorizar largas listas de comandos. Consiste en comprender el sistema de archivos, construir rutas correctas, anticipar el efecto de cada operación, verificar resultados y registrar procedimientos. En Garuda se agrega una habilidad más: saber qué shell interpreta cada instrucción y qué alias se interponen entre lo que se escribe y lo que se ejecuta. fish hace más cómodo el trabajo diario; Bash sigue siendo el lenguaje común de los scripts. En trabajos de Ingeniería Biomédica, estas capacidades reducen errores de organización y facilitan la reproducción de análisis, la gestión de conjuntos de datos y la automatización posterior con Python, R, Git o Quarto.
